                                    TiffinHub – Smart Tiffin Management System

A modern, subscription-based tiffin management platform connecting customers with trusted local home chefs and tiffin providers. Built to simplify daily meals, ensure hygiene, and bring homely food right to your doorstep.

🚀 Overview

TiffinHub is a full-stack web application designed to revolutionize how people access daily meals. It allows users to subscribe to affordable meal plans, discover verified local vendors, and enjoy a seamless food ordering experience.

This project simulates a real-world SaaS product with role-based access (Admin, Vendor, Customer) and focuses on scalability, trust, and user experience.
